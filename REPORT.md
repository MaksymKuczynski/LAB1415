## Етап 1. Вибір та обґрунтування Pet-проєкту

### 1.1. Назва проєкту

**CurrencyConvertBot** — Telegram-бот для миттєвої конвертації валют та моніторингу офіційних курсів НБУ.

### 1.2. Опис ідеї

Проєкт являє собою асинхронного Telegram-бота, який дозволяє користувачам швидко переглядати актуальні курси основних іноземних валют відносно гривні та виконувати точну конвертацію довільних сум між будь-якими підтримуваними валютами безпосередньо у месенджері. Бот автоматично отримує дані з відкритого API Національного банку України та кешує їх у пам'яті для миттєвої відповіді.

### 1.3. Обґрунтування вибору

- **Актуальність:** Швидка перевірка курсу та перерахунок сум у різних валютах є щоденною потребою при онлайн-покупках, розрахунках за послуги, плануванні подорожей та роботі з іноземними замовниками.
- **Цільова аудиторія:** студенти, фрилансери, мандрівники та звичайні користувачі месенджера Telegram.
- **Конкурентні переваги:** відсутність потреби встановлювати окремі додатки чи відкривати браузер, миттєва швидкість роботи завдяки локальному кешуванню курсів, простий текстовий синтаксис команд і підтримка крос-курсів між будь-якими валютами зі списку НБУ.

### 1.4. Технологічний стек

- **Мова програмування:** Python 3.10+
- **Основний фреймворк/бібліотека:** `aiogram` (версія 3.x)
- **База даних:** In-memory кешування курсів (з можливістю розширення до SQLite)
- **Інструменти тестування:** `pytest`
- **Інше:** `aiohttp` (асинхронні HTTP-запити до REST API НБУ), `python-dotenv` (управління конфігурацією), Git / GitHub.

## Етап 2. Планування розробки

### 2.1. Декомпозиція проєкту (Задачі)

| № | Назва задачі | Опис | Виконавець |

| 1 | Ініціалізація репозиторію та конфігурації | Налаштування структури `src/`, `requirements.txt`, `.env.example`, реалізація завантаження змінних середовища (`src/config.py`) та точки входу (`src/main.py`). | (ПІБ студента 1) |
